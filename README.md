# Хмельницький: історія вулиць — перша дослідницька версія

## Що реалізовано
- Інтерактивна карта на Leaflet + OpenStreetMap.
- Завантаження названих вулиць міста з Overpass API.
- Пошук за назвою; у переліку показуються унікальні назви вулиць.
- Інформаційні картки з попередніми назвами, роками та короткими довідками.
- Підготовлено 10 чернеток аудіосценаріїв українською мовою (орієнтовно до 1 хв).
- Підтримка окремих MP3-файлів для кожної історії.

## Важливо про аудіо
У цій версії додані саме тексти дикторських сценаріїв, а не MP3. Якісний природний чоловічий український голос не слід підміняти російськомовним синтезом. MP3 можна під'єднати, коли буде готовий запис або доступний український TTS-голос. Для кожної історії у `data/stories.json` заповнити поле `audio`, наприклад:
`"audio": "assets/audio/proskurivska.mp3"`.

## Запуск локально
Потрібен вебсервер (не відкривайте index.html подвійним кліком):
```bash
python -m http.server 8000
```
Потім перейдіть на http://localhost:8000

## Публікація
Сайт можна опублікувати на GitHub Pages або іншому статичному хостингу. Для стабільної публічної роботи рекомендовано згодом зберігати перевірений GeoJSON локально, щоб не залежати від доступності Overpass API. Дотримуйтеся умов використання тайлів OpenStreetMap та вказуйте атрибуцію.

## Структура
- `index.html` — головна сторінка
- `styles.css` — оформлення
- `app.js` — карта, пошук, картки та аудіоплеєр
- `data/stories.json` — історичні довідки та сценарії
- `assets/audio/` — готові MP3-файли (поки порожня)
